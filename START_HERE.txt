# BASE — Your App System

This is your creator app system.

To use it:

1. Get a Creator Key (GitHub Personal Access Token)
   → On GitHub: click your profile photo → Settings → Developer settings
     → Personal access tokens → Tokens (classic) → Generate new token
   → Give it "repo" scope (full control of private repositories)
   → Copy the generated token — this is your Creator Key
   → Keep it private; anyone with this key can edit your repository

2. Open the Creator Dashboard
   → Go to: /creator-Dashboard/index.html

3. Enter your Creator Key

4. Enter your content.json URL
   → The first time you use the Creator Dashboard, this field will be blank.
   → After you load your app once, the dashboard will remember this URL on this device.

5. Click "Load Current State"

6. Edit and Publish your app

---

⚠️ Note:
The Fan App will not display correctly if opened directly from this folder.
It must be published (GitHub Pages or other hosting) to fully work.
